# 宁波市人才工程项目申报书 · 字段说明（替代 PDF）

> 本文件是官方申报书的**完整字段清单**，作为创业者端"项目详情 + 报名表单"的**字段权威来源**。
> 来源：官方申报书样本（制造业项目·人才类）。Claude Code 的 PDF 工具不可用时，**以本文件替代 PDF**。
> 平台为**宁波平台**：原模板中的"来甬"在本平台一律为**"来宁"**。
> 标记说明：`[结构体]` = 可增删多条、单条必填校验、父级以"n 条"聚合显示；`[必填]`；`[需验证]` = 硬指标，验证通过后方计入雷达/作真实展示；`[派生]` = 由结构化字段自动算出。

### 三、阶段性目标

- 阶段性目标 `[结构体]`（≥2 阶段，未来 5 年不含申报年份）：阶段、开始时间、结束时间、预计投入情况、阶段性目标
- 项目总投入预测（万元，按 5 年估算，不含申报年份）：
  - 总投入预测
  - 其中 1. 用人单位已投入资金（含直接投入、各级各类课题资金）
  - 其中 2. 已获区（县、市）支持资金
  - 其中 3. 未来 5 年用人单位计划投入资金

### 五、预期贡献及验收指标

> 每项含"数量"+"描述（≤200 字，对照数量做文字描述）"。建议做成数量型字段组：

- 发明专利：申请 / 授权
- 实用新型：申请 / 授权
- 国际专利：申请 / 授权
- 技术标准：国际标准 / 国家标准 / 行业标准 / 企业标准
- 新产品 / 新材料 / 新装备 / 新工艺 / 新服务 / 软件著作权 / 临床批文 / 生产批件 / 医疗器械注册证
- 论文：发表总量 / SCI·EI 收录 / 国内核心期刊（除 SCI·EI 外）
- 专著总量
- 科研获奖：国家级 / 省部级（总量）
- 承担项目情况：国家级 / 省部级（总量）；横向项目 / 单位内设项目
- 人才引进（或培养）：博士 / 硕士 / 科研骨干
- 其他

## 给 Claude Code 的使用约定

1. 创业者端"项目详情"与"报名表单"的可填字段，**严格以本文件为准**，1:1 落库与渲染。
2. 凡标 `[结构体]` 的对象，统一用通用结构化集合组件实现（增删改 + 必填校验 + "n 条"聚合）。
3. 凡标 `[需验证]` 的字段，未验证不计入雷达、展示处标"未验证"。
4. 所有"来甬"为"来宁"；导出 Word 申报书的版式与字段顺序按本文件章节。
