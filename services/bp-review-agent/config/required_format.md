# BP 评审报告输出格式规范

参考：rk-vashista/pitch 的配置惯例

## 整体结构

报告由以下三个独立模块组成，按顺序输出：

1. **行业专家视角** (`### 🧠 行业专家视角`) — 技术与产品可行性
2. **投资人视角** (`### 💰 投资人视角`) — 市场与商业模式
3. **风险预警** (`### 🛡️ 风险预警`) — 商业化落地风险

## 强制格式规则

- 每个视角以 `###` 三级标题开头，**禁止在标题前加任何文字**
- **严禁开场白**：不得出现"好的"、"作为XXX"、"我已审阅"、"以下是"等引导语
- **严禁占位符泄漏**：所有 `[...]` 格式的模板描述必须替换为具体分析内容
- 风险视角必须使用 Markdown 表格，列：风险点 | 类别 | 严重度（高/中/低）| 缓解建议
- 每个视角末尾必须有一句总结性结论
- 语言：中文，专业术语保留英文缩写（TAM/SAM/SOM/CAC/LTV/runway）

## 报告头（系统自动生成）

```
# BP 评审报告（[模式标签]）
_生成时间：[datetime]_
```

模式标签：
- 模式 A：`直接评审`
- 模式 B：`标准评审 · 含历史修改意见`
